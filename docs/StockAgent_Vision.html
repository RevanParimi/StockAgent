🎯 The Core Idea
One sentence that captures everything we are building.

A money-making tool that watches every pointer that affects a stock — technical, fundamental, macro, news, sector — and when enough signals align, it acts.

Most investors lose because they react emotionally, lack information, or can't process 20 signals at once. This system does it systematically, 24/7, across all NSE/BSE listed stocks, MFs, and eventually F&O — for a group of 10+ people investing together, with plans to scale.

The Three Design Principles
🎯
WHAT + WHY + HOW MUCH
Every signal answers three questions. Not just "buy HDFC Bank" — but WHY (which pointers fired), and HOW MUCH (position size based on conviction). Without all three, signals are useless.
⚖️
Confluence = Conviction
One signal firing is noise. Multiple independent signals pointing the same way is conviction. The more pointers that align, the higher the conviction, the larger the position size.
🔄
Gets Smarter Every Day
Every prediction is tracked against reality. Wrong agents get penalized, accurate ones earn more weight. Pattern lessons accumulate. The system learns which pointers matter most for each stock.
The North Star Metric
Signal conviction drives action size. This is how we avoid both over-trading and under-conviction.

Risk Controls at Every Step
  • Every signal comes with a stop-loss level — hard stop % by bucket (large: −5%, mid: −8%, small: −12%)
  • Kelly Criterion position sizing — half-Kelly, updated monthly as RL accumulates outcome data
  • Portfolio caps — no single stock >10%, no single sector >40% (except confirmed sector rotation)
  • Thesis-break exit — if the original signal reason is invalidated, exit regardless of P&L
  • Time stop — position not moving after 20 trading days = opportunity cost exit
  • Confluence-drop exit — when confluence score falls below threshold, exit. The edge is gone.
  • In Phase 3, all signals require SEBI algo registration compliance — full audit trail maintained
🧠 Intelligence Layer
How the AI actually processes signals — multi-agent analysis, RAG memory, and RL continuous learning.
🤖
Multi-Agent Analysis
Each stock is analyzed by multiple specialist AI agents simultaneously. Each agent looks at one narrow dimension — Technical, Fundamental, Macro, Sentiment, Sector etc. A Signal Aggregator fuses all scores using earned, RL-adapted weights.
📚
RAG Memory
A vector knowledge base stores earnings call transcripts, RBI circulars, SEBI filings, analyst reports, and past analyses. Agents retrieve relevant context before making decisions — giving them institutional memory.
🔄
Reinforcement Learning
Every prediction is tracked against actual price movement. Wrong agents lose weight. Accurate agents earn more influence. Pattern lessons accumulate per stock, per sector, and market-wide. The system gets smarter every single day.

RL Learning — How The System Gets Smarter
Daily Learning Cycle (4:30pm IST after market close)
  • Load today's prediction → fetch actual close from market data
  • FeedbackAgent reasons about WHY each miss happened (data gap? wrong model? external shock?)
  • Agents that were wrong get their weight reduced. Agents that were right get more influence.
  • New pattern lessons are stored: "Last 3 days of month, sales agent overestimates demand"
  • Lessons propagate: stock-specific → sector-wide → market-wide when applicable
  • Tomorrow's analysis starts with a smarter, updated model

🐟 MiroFish — Macro Scenario Engine
MiroFish builds digital simulation worlds to rehearse the future. It is our forward-looking macro pointer — telling us what might happen before it does.

What MiroFish Does

You feed it seed materials (RBI policy PDFs, annual reports, macro data, news summaries) and ask a natural-language question like "What happens to banking stocks if RBI cuts rates by 50bps while FII flows stay negative?" It builds a digital world, spawns thousands of AI agents with distinct personalities, runs parallel simulations, and produces a prediction report — letting you rehearse the future in a sandbox before acting with real money.

Where MiroFish Plugs Into Our Signal System
  • Macro Pointer — MiroFish output is treated as a forward-looking macro signal, weighed alongside live macro data
  • Pre-Signal Stress Test — Before any Strong Buy/Sell fires, run a 30-min scenario to challenge the thesis
  • Risk & Macro Agent — Gets MiroFish scenario probabilities as additional context
  • Sentiment Agent — MiroFish simulates how thousands of investors would react to a news event
  • Policy Agent — Test "what if FAME subsidy is cut 50%?" before it happens
  • F&O Layer (later) — Simulate FII outflow scenarios to size BankNifty positions

Institution-Type Weighting — The Core Differentiator

A bank, an insurance company, an AMC, and an NBFC are all "BFSI" — but they need completely different analysis. Every sector applies similar sub-type routing. An insurance stock gets Insurance Signals agent weighted at 30%. A bank gets Credit Quality weighted at 20%. A pharma company doing US generics gets USFDA agent at 25%. No generic screener does this.

🏦 Multi-Account Architecture
Not just 10 people with individual accounts. One shared intelligence layer running across many accounts simultaneously — each account benefits from what every other account taught the system.

The Core Insight

More accounts = more live trade outcomes = RL trains faster. A signal that failed on 80 out of 100 accounts gets penalized immediately. A signal that worked on 90 out of 100 gets reinforced immediately. No single-account system can compete with this learning speed. This is the real competitive moat — shared intelligence, isolated risk.

🧠
Shared Intelligence
One brain. The RL system, RAG knowledge base, agent weights, and pattern lessons are shared across all accounts. Every outcome from every account makes the system smarter for every other account. New accounts benefit immediately from everything learned before they joined.
🔒
Isolated Risk
Each account's capital is completely separate. One account's losses don't affect another. Each account has its own risk profile, position sizing, drawdown limits, and broker connection. The brain is shared — the money is not.
📈
Flywheel Effect

Logic 4 — Entry is Not When Signal Fires. Entry is When Risk/Reward is Best.

Signal fires → system does NOT immediately enter. It asks: Is there a better price in the next 24–48 hours? Is there a support level nearby that makes the stop loss tighter and risk/reward better? The difference between optimal entry and signal-fire entry is 1–2% per trade. Compounded across hundreds of trades — significant alpha.

Logic 5 — Position Sizing is the Real Alpha Generator

A 55% win rate system with correct Kelly sizing beats a 65% win rate system sized by gut feel — consistently. Half-Kelly is the practical implementation. Then three adjustments:

Volatility Adjustment
A stock moving 3% per day gets a smaller position than one moving 0.5% per day. Same conviction, different size. Volatility = uncertainty = smaller bet.
Correlation Adjustment
Already hold 3 banking stocks? 4th banking signal gets smaller position regardless of conviction. Marginal risk contribution is high — marginal reward is not.
Account Type Adjustment
Core account: max 5% per position. Alpha account: max 15%. The account type itself is a hard constraint on sizing that overrides Kelly.
Logic 6 — Position Management. Where Most Systems Fail.
Trade moves in your favour
  • At Target 1: sell 30–40%. Lock in profit. Reduce risk.
  • Move stop loss to breakeven. You cannot lose now.
  • At Target 2: sell another 30%. Trailing stop on rest.
  • Let remainder run. Biggest returns come from this.
Trade moves against you
  • Stop loss hit → exit. No discussion. No waiting to recover.
  • Thesis breaks → exit immediately regardless of price.
  • Average down ONLY if thesis is stronger, not just cheaper.
  • Never hold a loser because you "believe in it."
Trade goes sideways
  • Time stop: if thesis hasn't played out in expected timeframe → exit.
  • Capital tied up in a sideways stock is capital not working elsewhere.
  • Opportunity cost is a real loss even if price hasn't moved.
Logic 7 — Exit Logic Has Three Categories
A — Profit Exits
  • T1: take 30–40% at first resistance
  • T2: take another 30–40% at second target
  • Trailing stop on remainder
  • Never wait for the perfect top
B — Loss Exits (Most Important)
  • Stop loss: predetermined at entry
  • Thesis break: exit immediately when core assumption is wrong
  • Thesis break exits override everything — even if price hasn't moved
  • Time stop: exit if no movement in expected timeframe
C — Signal-Driven Exits
  • System generates Sell on something you hold → exit
  • Sector score drops below threshold → reduce all sector exposure
  • Portfolio correlation spikes → reduce overall exposure

Logic 10 — Learning Logic. The Reason Must Match the Outcome.

The Critical Rule Everyone Gets Wrong

A trade that made money for the wrong reason is MORE dangerous than a trade that lost money for the right reason. If you credit the wrong agent for a lucky outcome, you corrupt the entire learning system.

4 Levels of Learning
  • Level 1 — Was the direction correct? (Stock went up/down as predicted)
  • Level 2 — Was the REASON correct? (Did the thesis play out as stated)
  • Level 3 — Was the timing correct? (Did it move in the expected timeframe)
  • Level 4 — Did it help the PORTFOLIO? (Contribution to overall performance)
RL credit is only given when direction AND reason align. Lucky trades with wrong reasons get no credit.
Example
System buys MARUTI because fundamentals strong + sector tailwind.

Stock rises 20% — due to M&A rumour. Nothing to do with fundamentals.

❌ Fundamental agent should NOT get credit.
⚠ Event detection should be flagged as a miss.
✓ System learns: event radar needs strengthening for M&A detection.
Logic 11 — The Logic of When NOT to Trade

The patience filter is not a module. It is a philosophy embedded throughout the entire system. The system should generate "Stay Out" more often than it generates Buy or Sell. High conviction moments are rare — the system should only act when the edge is clear.

Stay Out: Signals conflict across dimensions
Stay Out: Market breadth deteriorating rapidly
Stay Out: Last N signals for this stock all wrong
Stay Out: Corporate action pending, outcome uncertain
Stay Out: Extreme volatility, poor risk/reward
Stay Out: Portfolio already at max concentration
The Single Most Important Logic
Every rupee that is not lost is a rupee that compounds.
All the entry logic, signal generation, and return enhancement in the world matters less than the fundamental discipline of protecting capital. A 50% loss requires a 100% gain to recover. A 20% loss requires a 25% gain. A 10% loss requires only an 11% gain.

The system should be designed first to not lose money. Returns follow from that.
