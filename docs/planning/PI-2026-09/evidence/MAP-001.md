## Choices the card left open

- **Logic trees** are indented text in the YAML (two spaces a level, `| ` continues a line); the
  model holds them as nested nodes for the viewer, and `TREES.md` draws the branches.
- **Ownership:** an exact path beats a pattern, a sub-module beats its module, and a file two other
  owners claim fails the guard, like a file nobody claims.
- **Routes** are assigned by the longest path prefix, with no catch-all, so a new router fails.
- **The guard compares more than the generated part:** the whole model and `TREES.md`, byte for
  byte, so a curated edit without a run or a hand edit fails too. The stamp is not compared.
- **Stamp:** the commit at generation, with a flag when the code differed from it.
- **Files read:** those git tracks plus new ones it does not ignore, so an ignored scratch file
  cannot make one machine's model differ from CI's.
- **Gates and routes:** a shape the readers do not know stops them with the line, never a guess.
- **Production claims left the trees:** they are `production.yaml` entries citing KT section 1,
  shown beside the switch and in their own table.
- The trace of one stock's life is in the model now (MAP-003 plays it); tours are empty.
