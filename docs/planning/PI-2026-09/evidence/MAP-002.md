## Choices the card left open

- **Flow marks are curated, not guessed from the words.** Each mark was checked against the code
  (`decide`, `execute_advice`, `run_daily_review`, `analyse`, `run_discovery_cycle`, the gate,
  aggregator, sector registry). Unmarked trees (the other modules, MAP-005's) draw as plain steps.
- **Trees reworded so a chart can be true** (TREES.md changes with them): M3.4 names its three
  outcomes; M3.5 labels its three paths (a switched-off sector also goes generic); M4.2 step 4 asks
  one question and then runs the feedback agent; M5.2 ends each check in its verdict and draws
  SWITCH, the tax wait and notes after them; M5.3 says every trade pays costs (sells too); M6.1
  dives re-dives first, as the code calls them; M6.2, M6.3, M6.4 have one line each rewritten.
- **A decision is an elongated diamond**; two or more detail lines (one under a decision) share a
  dashed list box; ELK lays a tree downwards when it has an order, rightwards otherwise.
- **Views:** the side view uses a 13° lens from far away; below is from below and in front; a
  selected module is framed from the front; the top plane stands behind the product plane.
- **Keys beyond the card:** arrows turn, `+`/`−` zoom, Shift+arrows move, `P` pauses motion.
- **The page holds a copy of the model.** A test fails when its modules, logic, flows, stores,
  jobs, settings or production values differ from `model.json`; routes, file lists and the commit
  in the header are as new as the last rebuild. The header reads "809a5ea, plus changes not in that
  commit" because this story's own change to the guard was uncommitted when the model was read.
- **Reduced motion** is done now (camera jumps, dots stand still). **Phone layout and the 2D
  fallback** wait for MAP-005; without WebGL the page says so and the legend and panel still work.
