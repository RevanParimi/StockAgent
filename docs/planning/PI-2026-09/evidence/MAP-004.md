## Choices the card left open

- **Developer view only**, as the design spec says. Its address (`#g`, `#g&m=M5`, `#g&f=<path>`)
  opens that view; changing to Manager returns to the world.
- **One selection for both tabs:** a module or part chosen in the world lights its files; a file
  chosen in the galaxy selects its part, so "Show in the world" and `G` show it.
- **Balls stand where the modules stand** (left to right and height as in the world), drawn
  further apart and pushed until none touches; shared files have a ball under the base frame. A
  dot's area grows with the file's lines. A file that others import is pulled to the side facing
  them; six or more other modules gives it a ring and a name (12 files today).
- **Front view looks down more steeply** than the world's, so balls behind one another come apart.
  Choosing moves no camera; a view the person turned stays theirs.
- **The panel is the text equivalent:** a module's panel lists its files, so every file is reached
  from the keyboard, with or without WebGL.
- **Search:** every Python file by name (module-owned and shared ones are new). A file opens in
  the galaxy when the galaxy shows, when no world panel lists it, or when it is shared.
