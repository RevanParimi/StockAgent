## What was built

`autopilot/box_events.py` (new) reads `~/devbox/events.log` and never writes it.

| Rule | How |
|---|---|
| What holds | a `BOOT`, `OOM_KILL` or `ANOMALY` not yet seen; a log that is missing, unreadable, empty or without one event line; a check that itself fails. `RC_EXIT` and unknown kinds are only listed |
| When it looks | before each phase, on every turn of a running phase, before a push and again right after its test run, while waiting for a push window, at `start` and `status` |
| While held | no next phase, no push, nothing typed into a phase (no usage-limit or API-error retry, no reminder). A phase still working may finish; then the runner ends |
| Interrupted | a restart marks the phase that was running at the restart time. After `OOM_KILL` or `ANOMALY` the runner marks a phase when it cannot go on (usage limit, API error, exit); with no runner alive, the unfinished phase. Never one that finished, had exited, or was ended on purpose (`STOPPED`: `stop now`, a login problem) |
| Seen | `autopilot.sh seen` (the owner's word), then `start`. `start` refuses before that |
| Told | one entry in `SESSION_LOG.md` per new event; `box-event-for-handoff.md`, which the next phase moves into HANDOFF.md |
| `status` | memory now (`anon`, `file`) and 5 events at most, those not seen first kept |
| Late and double lines | a line counts by when it was written (a late one is not missed); a restart counts by its time, `BOOT` line less `pid1_up`, so a second line about it is not counted twice |
| Kept | `box-events.json` (constant size, 20 restart times); the handoff file, 20 lines. No process line of the log is ever copied |

`autopilot.sh` calls it (new `check` and `seen`); `prepush-suite.sh` asks before and after the
suite; `protocol.md` has each phase run `check` first.

## Choices the card left open

- **Handoff:** a flag file the next phase writes into HANDOFF.md, not a commit by the runner (a
  runner editing the checkout would block its own push).
- **How `start` knows you saw the event:** a separate `autopilot.sh seen`. A session runs it only
  at your word.
- **No time limit ends a held phase** (the check's finding M1): a stuck one is ended with
  `stop now`.
