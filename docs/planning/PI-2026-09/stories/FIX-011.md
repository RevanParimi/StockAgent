# FIX-011 — NSE's per-symbol meta API is gone: restore the surveillance and suspension guards and an industry source

Priority: **P1** · Scope: **routed** from PR-004's implementation (found on the way, 2026-10-20;
the owner delegated routing calls on 2026-10-13) · Estimate: **2 points**

Status lives in [STATE.json](../STATE.json), not this card. No dependencies. Order it before
[SA-049](SA-049.md), which buys shelf ideas with idle cash: the guards below are what keep
operator-pattern and suspended stocks off the shelf. Evidence: **a probe of NSE's public
endpoints from this machine and the local cache**. Production was not read.

## What was found

`services/data/fetchers/surveillance.py` `get_symbol_meta()` calls the `nse` package's
`equityMetaInfo()`, which requests `https://www.nseindia.com/api/equity-meta-info`.

- On 2026-10-20 that endpoint answered **404 Not Found** for all six symbols tried: LIQUID1,
  CASHIETF, NIFTYBEES, MARKSANS, STYLAMIND and EMBASSY
  (`analysis_data/pr004/meta_probe.py`). NSE's `quote-equity` API answered 403 from this
  machine (`quote_probe.py`).
- The local cache `data/market_cache/symbol_meta.json` holds 82 entries from 11 Jul, all
  `degraded: true`.
- To check while fixing: the code reads `surveillance` and `metadata.status`, but the `nse`
  package describes this endpoint as carrying the industry, the ISIN and status flags
  (suspended, delisted, FnO, ETF, debt). So the surveillance gate may never have fired, even
  before the 404 (not verified: no response was seen).

**Effect (code inspection):**

- `core/discovery/guards.py`: the ASM/GSM and suspension gates never test a symbol. Every
  shortlisted symbol is recorded as `surveillance:<SYM>` in `degraded_checks` and passes.
- `core/discovery/deep_dive.py` `infer_sector()`: no industry ever arrives, so every symbol
  outside the registry's ticker map is `generic`. On the production shelf of 11 Oct, 5 of 9
  ideas were `generic` (product review section 11), and all 10 in July's local copy were.
- SA-050's sizing counts a holding's `sector`, so `generic` holdings share one 30% bucket. With
  about ₹83,000 positions on ₹10 L (SA-049's 12 holdings), a fourth such holding is cut to
  about 5%. See the SA-049 card note.
- [SA-044](SA-044.md) (peer choice) and [SA-026](SA-026.md) (sector lenses) both plan to read
  NSE's `industry` through this same call.
- The home page's extended list (`services/api/routes/ui_data.py` `_ALL_TICKERS`) holds
  two stocks outside the ticker map, CEATLTD and TIINDIA. A home-page watchlist BUY of
  either that is not a managed ticker is keyed `generic` (PR-004's `holding_sector` falls
  back to `infer_sector`), so SA-050's cap counts it outside automobile: with MARUTI and
  M&M at 28%, CEATLTD at ₹3,000 takes the full 10%, and automobile exposure reaches about
  38%. Once a managed record exists its sector wins, so the fix must not re-key an
  existing record (this card's hard-review question). PR-004 re-review RR-L1.

PR-004 did not depend on it. Its "only companies" rule reads the ISIN from NSE's archive
bhavcopy, and its sector cap reads Yahoo's classification (`market_classification`).

## Intended result

- The screen's surveillance gate tests ASM/GSM membership from a source that answers, and a
  suspended or delisted symbol is rejected. A source that cannot answer still degrades
  visibly, never silently passes everything for months.
- One industry and sector source feeds `infer_sector`, SA-044 and SA-026. Choose between
  NSE's archive files, Yahoo's classification (which PR-004 already stores on shelf ideas) or
  another documented source. Record why.
- The watchdog, or SA-040's per-source fetch health, notices when a per-symbol source degrades
  for every symbol for more than a week.

## Acceptance criteria

- A fixture ASM/GSM list rejects a listed symbol and passes an unlisted one. A fixture
  suspension rejects the symbol.
- A source that answers for no symbol produces one visible degraded state per run, not one
  per symbol, and the weekly run's summary says so.
- `infer_sector` maps a fixture industry for a stock outside the ticker map to a real key. A
  characterization test shows what that changes in graph routing, and the prediction-store
  paths keyed by `sector` stay consistent for existing holdings.
- No test reaches the network (tests/hermetic.py).
