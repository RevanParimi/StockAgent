# FIX-013 — Move the fast and reasoning LLM tiers to cheaper current models

Priority: **P2** · Scope: **user-requested** (owner, 22 Oct 2026, about 22:30–23:35 IST) · Estimate:
**1 point**

Status lives in [STATE.json](../STATE.json), not this card. Dependencies: none. Source: the owner
asked to replace the LLMs, which "seem very old", with cost and efficiency first and any
provider allowed. They then chose the "split vendors" set after Claude Haiku 5.5 and Qwen3.8 Flash
failed the benchmarks.

## Intended result

The fast and reasoning tiers move to models that cost less, and they show no loss on the checks
our two benchmarks measure. The bulk tier stays where it is.

| Tier | Before | After |
|---|---|---|
| Fast (chat tool loop, 08:45 pre-open shock rating) | `qwen/qwen3.6-flash` | `deepseek/deepseek-v4.1-flash-1017` |
| Reasoning (unified analyst, aggregator verdict, FeedbackAgent, ThesisReviewer, control lane, chat fallback) | `z-ai/glm-5.2` | `xiaomi/mimo-v2.6-pro` |
| Bulk | `deepseek/deepseek-v4-flash` | unchanged |

**Example.** A unified-analyst call reads about 7,440 tokens and writes 2,957. At list price it cost
about 2.04 US cents on glm-5.2, and it costs about 0.58 cents on MiMo-V2.6-Pro. The four-question
chat benchmark cost $0.0118 on qwen3.6-flash and $0.0059 on DeepSeek V4.1 Flash 1017. Turns took
14.0 s on average instead of 20.6 s.

## Acceptance criteria

- `config.yaml` names the new fast and reasoning models, and bulk is unchanged. The fallbacks in
  `base.py`, and the chat fallbacks in `ui_data.py` used when settings fail to import, name the
  same models.
- Each new model:
  - is one whose reasoning OpenRouter reports as optional (`reasoning.mandatory` false), so
    `JSON_MODE_EXTRA_BODY` can switch it off;
  - returns parseable `json_object` output in 6 of 6 `scripts/reasoning_bench.py` runs with
    reasoning off, and restraint holds.
- The fast model has no fabricated source, skipped tool or broken answer on the
  `scripts/model_bench.py` battery, and it is faster than the model it replaces. The fast tier
  also serves the pre-open JSON check.
- The reasoning model comes from a different vendor than the fast model, so the chat fallback
  still answers when one provider fails.
- Every tier model has a cost rate, and the reasoning call is priced at its own rate. Hand-worked
  expected values check this. The previous tiers keep their rates, so a rollback is still priced.
- The living docs that name the tiers describe the current models: CODEBASE, README,
  AGENTIC_DESIGN, ARCHITECTURE, CHAT_ARCHITECTURE, PRODUCT_MAP and RL_DESIGN.
- Production verification is separate. After the deploy, telemetry shows the new model ids with
  successful calls for chat, the pre-open check and the unified analyst. The owner confirms that
  no Railway `LLM_MODEL_*` variable overrides `config.yaml`.
