## What was found

On 29 Oct, NSE answered with an empty list for 14 configured codes, read under NSE's codes
(`symbol_resolver.nse_symbol`):

AAVAS, ACCCEMENT, APL, DEEPAKNITRI, GATI, ICICIPRULI, IDEAFORGE, LTIM, MAHINDHOTEL, MCDOWELL-N, MTAR,
PVR, STARHEALTH, ZOMATO.

Under FIX-018 a decision on any of these is set aside, and two such decisions use the whole cap.
Without FIX-018 one decision fails the gate for good.

**Inference from the names, none of it checked:**
- Some may be old codes of renamed or merged companies (MCDOWELL-N, PVR, ZOMATO). Some may be
  misspelt codes (ACCCEMENT, DEEPAKNITRI).
- Others may be companies NSE simply lists nothing for. ETERNAL, Zomato's current code, also
  returned none on 29 Oct, so a mapping does not always help.
- An empty list for a code that has paid dividends (possibly ICICIPRULI, LTIM) would point to a
  stale code or to NSE's answer itself.

## Intended result

For each of the 14 codes, gather read-only public evidence:
- whether NSE still quotes the code;
- what NSE lists under any candidate code;
- an NSE circular or company filing for a rename, merger or delisting.

Then act on what the evidence shows:
- **Same listed security under another code:** add a registry entry (`config/instruments.yaml`, an
  `alias` or a `rename` with evidence, per its header). `nse_symbol` then asks NSE for the right
  code.
  - An entry also changes the Yahoo symbol priced for that ticker, so check each candidate against
    both NSE and Yahoo.
- **A company NSE lists nothing for:** no registry change. Record it in the receipt with the count,
  so the owner can see how often FIX-018's cap is at risk.
- **A code that no longer trades** (merged, delisted, a new basis): propose a non-active segment
  to the owner, and do not change it in this card. Quarantine stops new-risk advice, forecasts and
  learning for that ticker.

## Acceptance criteria

- A table in the receipt. For each code: NSE's answer under it and under the candidate code, the
  evidence (source, reference, date), and the action taken or proposed.
- A hermetic test for each new entry. `nse_symbol` resolves to the code whose NSE list the fixture
  answers, and grading reads that list.
- The registry's own validation (SA-008's tests) passes.
- The KT limit's count of empty lists is updated.
- The guide case that names the registry, if one does.
- The story file, the changed files and the full suite pass.

## Hard review

Is each mapping the same listed security, with exchange or company evidence, never a name match?
Could an entry join two price bases, such as a merger's successor priced as the old company?
Does any changed Yahoo symbol alter a live holding's price?
