# FIX-028 — A sold stock leaves the daily review

Priority: **P2** · Scope: **routed** from FIX-025's implementation of 2026-11-06 (session
`stockagent-main-77`; [receipt](../evidence/FIX-025-implementation.md), "Found on the way"; routing
delegated by the owner on 2026-10-13) · Estimate: **2 points**

Status lives in [STATE.json](../STATE.json), not this card. Depends on [FIX-025](FIX-025.md), which
edits the same discovery path. **Order:** after [FIX-027](FIX-027.md), before PR-005. **Measure before
switching deployment on** (below): it becomes a precondition if the measurement says so.
Evidence: code inspection. No production state was read, so the managed list's size is **not
measured**, and neither is what a sold stock's reviews cost.

## The problem

A buy promotes a stock to the managed list with origin `held`, reviewed daily (`promote_symbol`).
Nothing takes it off when the autopilot sells it: `demote_symbol` is called only from the API's
manual deletes. So:

- A sold stock keeps its daily review and monthly forecast for good, at LLM cost, though no portfolio
  holds it.
- `portfolio.max_managed_tickers` (40) guards LLM spend, and `held` and `manual` entries are never
  evicted, so sold stocks fill it.
- At the cap a new buy's promotion returns `cap_full`. The autopilot ignores the return value: the
  buy stands, with one log warning, and the new holding gets no daily review and no forecast.

**Example (illustrative figures).** 25 manual entries and 13 holdings make 38. Two more new stocks
fill the list. The next stock bought is held with no daily review, and nothing but a log line says
so.

## Measure first

A read-only count of the production list's enabled entries, by origin, with the owner's word. If the
enabled count plus the 13 or so holdings deployment aims for passes 40, this story goes before
switch-on.

## Intended result

- When the autopilot exits a stock and no portfolio holds it, and it is not on a user's own watchlist,
  it is demoted (`enabled` false). `manual` entries stay. `managed_sectors` reads disabled entries, so
  its sector key survives, and `promote_symbol` re-enables it on a re-buy.
- A buy whose promotion returns `cap_full` says so where the owner reads it, not only in a log line.

## Acceptance

- By the real executor and promotion: a full exit demotes; a TRIM, a stock another portfolio holds, a
  stock on a user's own watchlist and a `manual` entry do not; a re-buy re-enables under the same
  sector.
- The daily review skips a demoted stock and reviews a re-bought one.
- A `cap_full` buy is visible in the digest.
- Docs: KT section 8 (the sold stock's managed status), AUTOPILOT_GUIDE, guide cases.
