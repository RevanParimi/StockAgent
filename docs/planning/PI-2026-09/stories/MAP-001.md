## Why

The owner, 22 and 23 Nov 2026: understand the whole product "in ascii tree way", then as a
"visually stunning and detailed" 3D map that "will long last for any developer or techno
manager". A map drawn by hand is wrong within weeks: the code changes daily. Everything the map
shows comes from one model, partly generated from the code and partly curated, and a guard fails
when the two disagree. This card builds that model; MAP-002 to MAP-005 draw it.

## What it does

1. **Generators** in `tools/architecture_map/model/` (Python 3.11, standard library + PyYAML),
   reading source files only:
   - scheduled jobs from `services/scheduler/python/scheduler.py` (AST): id, cron fields, the
     flag that gates the job; the two slot loops give `ipo_refresh_am/pm` and
     `company_events_am/pm`, as `scripts/docs/check_kt_docs.py` already treats them;
   - API routes from `services/api/routes/*.py` and the routers' prefixes (AST, no import of the
     app): method, path, router file;
   - imports between the Python files of `core/`, `services/`, `src/backend/` and `scripts/`
     (AST), with each file's line count;
   - the config switches the curated part names, with their `config.yaml` defaults.
2. **The curated part** (`tools/architecture_map/model/curated/`, YAML): the 12 modules and their
   sub-modules, the flows between them (from, to, what travels), the stores and who reads and
   writes them, the logic tree of every sub-module, each job's and route's module, each module's
   file globs, and production values as `{value, source: "KT section 1", as_of}`. Its content is
   the seed walkthrough of 22 Nov (`seed-walkthrough-2026-11-22.md`, replaced on 27 Nov by
   [TREES.md](../../../architecture-map/TREES.md), as step 4 says): convert it,
   and **re-check every claim against the code of the day** (it was checked at `62580ab`). Fix what
   has changed and list each fix in the receipt.
3. **One output**, `docs/architecture-map/model.json`, deterministic (two runs, identical bytes),
   stamped with the commit it was generated from.
4. **`TREES.md`**, generated from the model into `docs/architecture-map/`: the walkthrough's
   trees, kept current. Once it holds everything the seed holds, delete the seed in the same
   commit. Keep `docs/architecture-map/walkthrough-2026-11-26.md`: the owner's dated reading copy
   (the seed's trees, the 22–23 Nov discussion notes, the map's phases and the 26 Nov status).
5. **The guard**, `tools/architecture_map/model/check.py`, exits 1 with a one-line reason and the
   fix when:
   - the generated part differs from a fresh run ("run `python tools/architecture_map/model/generate.py`");
   - a curated path, function or config key does not exist in the repository;
   - a job, route or Python file belongs to no module (a file may be assigned to `shared`);
   - a flow, store, trace or tour step names something the model lacks;
   - a production value cites no source.
   It runs in CI's guards job (`.github/workflows/ci.yml`).
