## Why

The world shows meaning; a developer also needs the code as it is: about 400 Python files and
their imports. A force graph is the right tool for that one view, and linking it to the world
answers "where is this module in the code, and what does this file belong to?".

## What it does

1. **A galaxy tab:** one node per Python file from the model's generated import graph, coloured
   by module (the curated file globs), sized by lines; edges are imports. The layout is seeded, so
   it is the same on every load and in every screenshot; instanced meshes keep it smooth.
2. **Linked selection:** selecting a module in the world lights its files in the galaxy, and a
   file selected in the galaxy shows its module in the world.
3. **File panel:** path, lines, module, imports in and out (each clickable); search by name.
4. **Clusters:** each module's files gather, so a file imported across modules shows as a
   bridge.
