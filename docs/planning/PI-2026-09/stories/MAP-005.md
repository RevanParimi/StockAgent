# MAP-005 — Every module's logic, the 2D fallback, polish, and a living map

Priority: **P2** · Scope: **owner request** of 2026-11-23 · Estimate: **3 points** · Lane:
**light** (developer documentation and tooling; nothing the app runs, ships or reads)

Status lives in [STATE.json](../STATE.json), not this card. Dependencies: [MAP-002](MAP-002.md),
[MAP-003](MAP-003.md), [MAP-004](MAP-004.md). Design:
[architecture map design](../../../superpowers/specs/2026-11-23-architecture-map-design.md).
Profit-path step: **none directly**; the owner asked for it.

## Why

MAP-002 checked the money path's flowcharts in depth. A map that lasts needs every module checked
the same way, a view that works without a GPU, and a rule that keeps it true as the code changes.

## What it does

1. **Every module's logic**, re-checked against the code of the day and shown as flowcharts: M1,
   M2, M4.1, M4.3 to M4.5, M5.1, M5.4 to M5.7, M7 to M12. Fixes go into the curated model and
   are listed in the receipt.
2. **2D fallback:** without WebGL, or on a narrow screen, the same model as a flat map with the
   same panel, keys and deep links.
3. **Polish:** transitions, bloom tuned for legibility, the help overlay, reduced motion when the
   system asks for it, phone layout, and a "code inspected" stamp on every view.
4. **A living map:**
   - AGENTS.md "Review and change boundaries" gains one line: a change that adds or moves a job,
     route, module, store or flow updates the map's model; the guard says what is missing;
   - KT section 13 names the guard beside the other documentation tools (no PDF rebuild: AGENTS.md);
   - a TEAM_TESTING_GUIDE case for the owner's walk-through of the map.

## Acceptance

- The Playwright test opens every sub-module's panel without a console error, and loads the 2D
  fallback with WebGL switched off.
- Screenshots (scale 2): the 2D fallback, one flowchart per module, shown to the owner.
- A full UI-CHECKLIST.md pass over the whole map (3D, 2D fallback, phone layout): the receipt
  lists every item as passed or not applicable, with a reason. The Playwright test checks that
  reduced motion stops the camera flights and particles, and that the map works from the keyboard
  alone. DESIGN.md matches what was built.
- The full suite, the browser suite and the guards pass.
- Receipt `evidence/MAP-005.md`: lane light, accepted without a fresh-session review; the
  owner's walk-through is the guide case, read when the owner chooses.
