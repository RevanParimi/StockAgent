# MAP-006 — The map's browser tests wait for what they read

Priority: **P1** · Scope: BACKLOG **B-53**'s trigger, seen 28 Nov 2026 at 00:31 IST, made it a story
(AGENTS.md: a backlog entry becomes a story when its trigger is seen). **B-59** is the same kind
of race and is fixed in the same pass · Estimate: **1 point** · Lane: **light** (browser tests of
the architecture map; no buy, sell, size or grade)

Status lives in [STATE.json](../STATE.json), not this card. Dependencies: none. Profit-path step:
**none directly**. It keeps a flaky test from holding the pushes that deploy accepted work.

## Why

- **B-53.** In `tests/frontend/architecture_map_galaxy.test.mjs`, the test "the world and the
  galaxy pass the focus and a search on" presses "/" in `find(ADVISOR)` (line 435) and waits
  30 s for `dialog.search[open]`. The search did not open on three runs: PR-007's and PR-018's
  full runs on 27 Nov, and the autopilot's pre-push suite at 00:31 IST on 28 Nov, which held a
  push of 8 commits. Each time the same code passed on the next run. The failing call follows
  two Escapes and the return to the world tab.
- **B-59.** In `tests/frontend/architecture_map_flat.test.mjs` (line 174), the test notes the
  zoom right after Esc closes a panel, before the map has re-measured its wider box. It failed
  once.

The autopilot pushes only when its guarded suite passes on the exact commit, so either race holds
every push it hits.

## What it does

1. Find why "/" is sometimes not taken at line 435: the key may reach an element that ignores it,
   the last dialog may still be closing, or focus may not yet be back. Make the test wait for the
   state the viewer needs before it presses the key. If the viewer drops a key a person would
   press, fix the viewer. A longer timeout is not a fix.
2. B-59: wait until the zoom has settled after the panel closes, then note it.
3. Leave each test's assertions as they are. Only the waits change.

## Acceptance

- Each race is named with its cause: code reading, plus a reproduction where one can be made
  (for example, a slowed browser).
- Each of the two files runs 10 times in a row under the memory guard with no failure, followed
  by the full guarded suite.
- The entry for B-53 and B-59 under "Closed" in [BACKLOG.md](../BACKLOG.md) records the fix
  and the run counts.
