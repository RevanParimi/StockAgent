# OPS-001 — Test-suite resource profile

Priority: **P0** (your P0-1) · Scope: **owner request** of 2026-11-26 · Estimate: **1 point** ·
Lane: **light** (a measurement; nothing the app runs, ships or reads; no buy, sell, size or grade)

Status lives in [STATE.json](../STATE.json), not this card. Dependencies: none; the owner's order
puts it right after BACKLOG B-12. Profit-path step: **none directly**; it keeps the machine that
builds the product up (the owner asked).

## Why

The owner, 26 Nov 2026: the box (Railway, 4 GB RAM cap, 2 vCPU) crashed at 07:56 IST after the
autopilot ran the full suite (7,024 tests, about 25 minutes, one process) inside a Claude session.
"As the owner I want to know what the full suite costs this box, so we can tell normal from a
leak."

## Terms

- Logs, read only: `~/devbox/mem.log` (a sample a minute: cur, anon, file, slab, top 4
  processes) and `~/devbox/events.log` (`BOOT`, `OOM_KILL`, `ANOMALY` for anon over 2,500 MB,
  `RC_EXIT`).
- **anon** is real process memory and must return to baseline. **file** is page cache: it may
  stay high, which is normal, and a sweep clears it.

## What it does (the owner's)

- Record before: idle cur, anon and file from `/sys/fs/cgroup` (`memory.current`,
  `memory.stat`).
- Run the full suite once, serially, nothing else heavy running; sample every 5 s to a separate
  log.
- Record: duration, peak anon, peak per process (pytest, chromium, node, claude), and the top 10
  test files by RSS growth (a pytest hook using psutil or resource).
- Record after: anon at +0, +5 and +15 minutes.

## Constraints (owner, 26 Nov 2026)

Do not modify `~/devbox/*` or `~/entrypoint.d/*`; read their logs only. No new background
processes. Any new log is capped. Read-only checks except the test runs this story needs. Leave
the web link and the tmux sessions `rc`, `memlog`, `sweep` and `login-b` untouched.

## Acceptance (the owner's)

- A report table: before, peak, after.
- Verdict **normal** if anon is back within 200 MB of the baseline by +5 minutes and the peak is
  under 2.5 GB; otherwise open [OPS-002](OPS-002.md) with the top offenders.
- Receipt `evidence/OPS-001.md`.
