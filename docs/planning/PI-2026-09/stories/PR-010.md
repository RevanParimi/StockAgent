## Intended result

A new member understands the product in one minute: what changed for my stocks, how my money is
doing against the market, what we would buy next and why, and a place to ask.

**Today (code).** Eleven screens (home, agents, portfolio, learn, prompt-lab, analytics, logs,
rl-monitor, inbox, settings, auth), plus a chat overlay and a Tweaks panel. Operator analytics
(weight drift, miss types, agent accuracy) sit beside customer pages, and internal words are
used throughout: verdict, conviction, agent take, agent breakdown, conflicts resolved, shelf,
regime.

**Members see four screens:**

| Screen | Contents | Built from |
|---|---|---|
| **Today** | The brief: your stocks overnight, before the open, market news | `brief-view.jsx`, PR-008 |
| **Portfolio** | You vs the Nifty; in stocks vs cash; each holding with its one-line case, "we're wrong if" and next check; recent trades with plain reasons; the weekly scorecard | `portfolio.jsx`, SA-051, PR-005, PR-007, PR-002 |
| **Ideas** | What we would buy next: the idea, why, the price we would pay, the line that would cancel it | Shelf API (`/discovery/shelf`), plain labels |
| **Ask** | Chat, with suggested questions about your own stocks | Existing chat |

Settings stays in the account menu. Inbox merges into Today.

**The owner also gets an Operator menu:** Agents, Analytics, RL Monitor, Logs and Prompt Lab,
unchanged.

**Removed:** the Learn page (course and quiz), "Browse by category", "Suggested for you", the
agent-vote bars, the analysis drawer's agent breakdown and conflicts (owner-only details), and the
Tweaks panel (owner and dev only).

**Plain words in all member copy:**

| Internal word | Member word |
|---|---|
| verdict | our view |
| conviction | confidence |
| agent take | why |
| shelf | ideas |
| regime | market mood (Calm, Cautious, Stressed) |

BUY, HOLD and SELL stay, each with a one-line meaning.

**The weekly scorecard's checks (PR-002 review F3, 2026-10-16).** The Inbox weekly screen marks
every clear or too-few-to-judge flag with "✓" (`weekly-view.jsx`). A tick beside "the check
needs 8" reads as "passed". Wherever the scorecard lands, mark "too few to judge" with a
neutral sign, as the email does ("Checked, too few to judge").

**Decision for the owner at implementation:** manual agent-weight tuning. It changes live
decision weights outside the contained learning policy (SA-039, `observe`). Recommended: keep it
owner-only under Operator and show the learning mode beside it. Alternatively, disable saves
while `observe` is on.

## Acceptance criteria

- A member session's navigation offers exactly Today, Portfolio, Ideas and Ask (plus the account
  menu); no operator screen is reachable from it.
- An owner session additionally offers the Operator menu.
- No member-visible copy contains a word from the internal list.
- The receipt lists member-visible sections before and after, with the reduction.
- Every screen renders an explicit unavailable state when its API fails.
- The responsive audit passes at phone width with no horizontal scroll.

## Unit and integration evidence
