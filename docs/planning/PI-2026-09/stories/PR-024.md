# PR-024 — An independent challenge to every BUY

Priority: **P2** · Scope: **paused** (owner decision of 2026-11-15, edge roadmap, stage 4) ·
Estimate: **3 points** · Lane: **decision path** (it can lower a conviction; fresh-session review)

Status lives in [STATE.json](../STATE.json), not this card. Dependency: [PR-017](PR-017.md) (the
grades that judge it). **Starts when** 100 ideas are graded at 30 sessions and the owner promotes
it.

**New conversation? Read first:** [EDGE-ROADMAP.md](../EDGE-ROADMAP.md) sections 1 to 3, 6 and 7.

## Why

On an investment desk nobody buys on one analyst's word; someone argues the other side. Here one
model call scores every dimension and writes its own risks.

## What exists

- `src/backend/shared/pipeline/unified_analyst.py`: one reasoning-tier call returns, per dimension,
  a score, `key_risks` and `bear_case_if`. The same model, in the same call, writes the case and
  its risks.
- `src/backend/shared/pipeline/signal_aggregator.py`: the composite; the verdict is bound to the
  composite's band. Nothing a risk says can lower the score.
- `core/discovery/deep_dive.py`: the weekly deep dives (at most 20) that produce BUY ideas.

**First step: confirm this is still true.** Search the prompts and the pipeline for any second
pass. If one exists, describe it in the receipt and narrow this card to what is missing.

## What to build

1. **A second call for each BUY-rated deep dive**, given the same dated evidence and the opposite
   brief: "argue this purchase is a mistake, using only this evidence". Its answer is a list of
   objections, each with the evidence it rests on and a severity.
2. **A fixed rule, not the model, decides the effect.** An objection that cites a hard fact the
   first pass did not use (a filing, a reported number, a red flag from [PR-023](PR-023.md)) marks
   the idea `challenged` and lowers its conviction by a set step.
3. **Shadow first.** Record both convictions for every idea. PR-017 grades both. The challenged
   conviction replaces the first only if challenged ideas did worse: 30 or more of them, 2 points
   or more worse at 30 sessions.
4. **Cost:** at most 20 more reasoning calls a week. Measure it in the receipt.

## Acceptance criteria

- An objection with no evidence reference has no effect.
- The challenger sees nothing dated after the dive.
- The same dive challenged twice gives one stored result (idempotent).
- "No difference" after 100 graded challenged ideas closes the card with the step switched off.
