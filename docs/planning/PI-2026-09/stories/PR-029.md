# PR-029 — Size by conviction, once proven

Priority: **P2** · Scope: **paused** (owner decision of 2026-11-15, edge roadmap, stage 5) ·
Estimate: **2 points** · Lane: **decision path** (it changes position size; fresh-session review)

Status lives in [STATE.json](../STATE.json), not this card. Dependency: [PR-018](PR-018.md).
**Starts only when** PR-018's rule has passed (conviction predicts returns at two monthly looks in
a row) and the owner promotes it. If that rule never passes, this card is closed unbuilt.

**New conversation? Read first:** [EDGE-ROADMAP.md](../EDGE-ROADMAP.md) sections 1 to 3 and 6.

## Why

Every new position is the same size, whatever the conviction. If the best ideas really are better,
equal sizes leave money on the table. If they are not, sizing by conviction only adds risk. The
owner's condition (4 Nov 2026): conviction sets size only after the scorecard shows it predicts
returns. PR-018 is that test.

**Example.** ₹12 L book. Today a 0.85 idea and a 0.56 idea each get ₹80,000. With tiers, they might
get ₹96,000 and ₹64,000.

## What exists

- `core/portfolio/deployment.py` `Breadth.position_inr`: a new position asks for the NORMAL share
  of equity over `portfolio.target_holdings` (80% ÷ 12, about 6.7% of equity).
- `core/portfolio/sizing.py` `size_buy`: applies the position cap (10%), the sector cap (30%), the
  cash floor and whole shares.
- Deployment buys the highest conviction first; conviction changes the order, not the size.

## What to build

1. **Three size tiers** by the conviction a dive was issued with, using PR-018's buckets: for
   example 0.8×, 1.0× and 1.2× of today's size. All still within the caps and the cash floor.
2. **Scaled down for a jumpy stock:** a stock whose daily moves are twice the book's average gets
   a smaller position, so each position risks a similar amount.
3. **Shadow first:** for 8 weeks record the size the tiers would have chosen beside the size
   bought, and what the book would have earned. The owner switches it on from that record.
4. One setting, per portfolio, off by default.

## Acceptance criteria

- An invariant test: no tier ever exceeds the position cap, the sector cap or the cash floor.
- The total asked for across a full book stays within the regime's target.
- With the setting off, sizes are identical to today's (a test).
- The tiers read the conviction as issued, never one revised after the buy.
