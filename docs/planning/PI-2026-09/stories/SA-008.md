## Routed input — 2026-09-27 SA-003 implementation

What SA-003 gives this story (implemented, awaiting its fresh review;
[receipt](../evidence/SA-003-implementation.md)):

- **An unresolved symbol already abstains.** No provider knows it, so its essential sections are
  empty and the decision gate says `abstain`. In enforce mode it reads INSUFFICIENT DATA, and no
  forecast, learning update or new-risk buy rests on it.
- **Minimum price freshness for grading and trading.** `daily_review._fetch_session_close` and
  `pricing.session_close` return `SessionClose(close, bar_date, source)`, and a close whose bar is
  not the session itself is not fresh. The fetchers still fall back to the newest earlier bar, so a
  suspended symbol keeps returning its last close. SA-003 made that visible; it did not change the
  selection.
- **Not done, and this story's: lifecycle identity.** `YF_SYMBOL_OVERRIDES` maps `TATAMOTORS` to
  `TMPV.NS`, the passenger-vehicles entity after the 2025 demerger. When TMPV's data is healthy,
  TATAMOTORS' analysis is `actionable`: the gate checks that evidence arrived and is fresh, not
  that it belongs to the same economic entity.
