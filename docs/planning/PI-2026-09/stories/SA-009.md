Build a read-only manifest listing store identity, ticker, sector evidence, schema, duplicates and consumers. Define canonical ownership and a reversible copy/quarantine migration, retaining lineage.

## Acceptance criteria

- No silent merge, deletion or guessed sector assignment.
- Manifest distinguishes missing metadata from confirmed sector and identifies conflicting duplicate forecast IDs.
- Dry-run and rerun produce deterministic plans; old data remains readable.

## Unit and integration evidence

- Fixtures include missing sector, duplicate identical rows, conflicting duplicates and wrong dimension roster.
- Verify dry-run leaves source hashes unchanged and rollback restores the same readable state.

Use deterministic fixtures and blocked external transports. Record exact commands, environment, results and any unsupported platform in the evidence receipt. Relevant existing tests plus these independent invariants are required; do not merely assert current implementation outputs.
