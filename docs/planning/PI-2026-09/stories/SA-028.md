## Routed input — SA-001 implementation (2026-09-26)

- **No Content-Security-Policy is sent.** Runtime Babel needs `unsafe-eval`, and index.html has inline scripts, so a useful CSP waits for the compiled client. Once it lands, add one as defense in depth behind SA-001's sanitizer: scripts from self (or the pinned CDNs), no `unsafe-inline`/`unsafe-eval`, and `img-src` limited to self.
- **Keep `npm run test:frontend` green.** Its harness mounts `ChatOverlay` under index.html's own `<head>` and transpiles `sphere.jsx` in the browser. Adapt it to the compiled bundle rather than dropping it. The pinned devDependencies in package.json must keep matching the production script pins; `tests/unit/test_chat_markdown_boundary.py` checks this. One known strictness (SA-001 review, I1): the harness's `__inspect` reports any href that `new URL` cannot parse, but a partial reference-style definition streamed up to `[r]: https://` renders `href="https://"`. That link is inert (a click opens `about:blank#blocked`, with no opener), so a future fixture of that shape should accept an unparseable `http(s)://` prefix rather than relax the protocol rule.
- **Bearer tokens stay in `localStorage`/`sessionStorage`** (audit F01), which is what makes any script injection costly. Moving them to an HttpOnly cookie changes CSRF handling; record it as an explicit decision, not a side effect of the build change.
