## Routed input — 2026-09-28 SA-005 review (L1, L2)

- **L1: the test boundary's reach is Python-level.** `tests/hermetic.py` sees Python's socket,
  DNS and file calls, and `curl_cffi`. The review reproduced four gaps:
  - a numeric-IP connection on Windows' asyncio proactor loop (`ConnectEx` is C-level);
  - the checkout reached through a Windows 8.3 or `\\?\` spelling;
  - directory listings, existence checks and native-library file I/O (pyarrow);
  - SQLite `file:` URIs, which `_checkout_path` skips.

  The application reaches none of them today, and KT §13 and `tests/TEST_DOCUMENTATION.md` now
  state the reach. **Still open:**
  - the module docstring says "whatever path spelling reached it"; correct it;
  - optionally, expand long names and `\\?\` in `_checkout_path`, parse `file:` URIs, and guard
    `BaseProactorEventLoop.sock_connect`.
- **L2: the broad-except guard's key has a blind spot.** Keys are path, function and ordinal of
  the silent handlers. So a change that fixes one grandfathered handler and adds a new silent one
  in the same function leaves the key set unchanged, and `scripts/ci/check_broad_except.py`
  passes. Its docstring says a new swallow trips it. Add a handler fingerprint (for example, the
  normalized `except` body) to the key. Also add a direct unit case that a non-logging call in a
handler (for example `cleanup()`) is still a swallow; today only the real-tree test catches that
weakening. The KT now states the blind spot.
