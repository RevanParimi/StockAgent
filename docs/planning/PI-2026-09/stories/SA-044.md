# SA-044 — Compare valuations only with same-industry peers

Priority: **P1** · Sprint: **2** · Provisional estimate: **2 points**

Status lives in [STATE.json](../STATE.json), not this card. Dependencies: none. Design: §2 and §6 phase 0 of the [one-engine design](../../../superpowers/specs/2026-09-26-one-engine-sector-lenses-design.md). Added 2026-09-26 at the owner's request (decision D7).

## Intended result

`bundle_builder._sector_peer_tickers` gives every **generic-graph** stock the automobile peer list. For example, `_sector_peer_tickers("generic", "SUNPHARMA")` and the same call for TATASTEEL both return MARUTI, TATAMOTORS, M&M, HEROMOTOCO and BAJAJ-AUTO (verified 2026-09-26). The generic prompt then asks for "P/E … vs named peers", so a pharma or steel valuation is judged against car makers. Elsewhere, peers are simply the first five names of a hand-typed list.

This small fix happens before the lens work (SA-026):

- **Pick peers from the same industry.** Use NSE's `industry` field (already read by `core/discovery/deep_dive.py` and `services/data/fetchers/surveillance.py`) across the known symbol universe, nearest market cap first, at most five.
- **Never use another sector's list.** When fewer than three same-industry peers resolve, the peer section says `peers unavailable` instead of borrowing another sector's names.
- **Label the source.** The bundle states how the peers were chosen, for example `peers: same NSE industry "Pharmaceuticals" (4)` or `peers unavailable`.

## Acceptance criteria

- No stock's peer list contains a symbol from a different NSE industry.
- A generic-graph stock with fewer than three same-industry peers gets `peers unavailable`, and never the automobile list.
- The four native sectors keep valid same-industry peers. Equivalence with today's lists is not required, because today's lists are "first five", not "nearest".
- The peer-selection rule and count appear in the bundle text and in the data-health record.
- Industry lookups are cached, so a bundle build adds no per-peer network calls beyond what exists today.
