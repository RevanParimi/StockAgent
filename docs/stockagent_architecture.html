INGEST
yfinance pulls MARUTI.NS: RSI=58.3, MACD=+12.4, steel ETF SLX=+3.8%. Serper returns: "FADA March dispatch +8% YoY". Today these land as raw text strings inside each agent's context.
NODES
TO BUILD → Parser emits typed node: {type:"technical_signal", rsi:58.3, tier:"INTRADAY", ttl_h:8} and edge: MARUTI → FADA_dispatch [confidence: 0.88]. Next run skips the Serper call if node is <8h old.
ANALYSE
LangGraph fires all 9 agents in parallel via Send API. Each calls Qwen3 with its context. SalesDemandAgent → 0.81 (FADA bullish). RawMaterialsAgent → 0.42 (steel risk). All 9 merge via _merge_dicts.
FUSE
SignalAggregator applies AGENT_WEIGHTS → weighted score 0.68. Conflict: SalesDemand(0.81) vs RawMaterials(0.42) delta=0.39 ≥ 0.30 → triggers LLM resolution. Verdict: BUY · 0.68 · "FADA dispatch offsets steel headwind"
LEARN
30 days later: MARUTI +6.2%. BUY correct. FeedbackAgent marks SalesDemand as most predictive. WeightAdapter: sales_demand 0.20 → 0.22. TO BUILD → graph edge MARUTI→FADA: 0.88 → 0.94 (system learns which signal actually predicted the move).
