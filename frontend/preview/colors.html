Color

Deep space, cyan, verdict spectrum.

The shell is almost black with a blue bias. Cyan is the only chrome accent. Everything else on the palette is a verdict — green for conviction, amber for neutral, red for caution. If a color isn't listed here, it doesn't exist in the product.
